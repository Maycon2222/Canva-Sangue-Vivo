# Canvas Business Model - Sangue Vivo

Documento HTML independente para apresentação do Business Model Canvas do projeto Sangue Vivo.

## Objetivo

Apresentar, em formato visual e profissional, o modelo de negócio do projeto, incluindo proposta de valor, segmentos de clientes, canais, relacionamento, receitas, recursos, atividades, parcerias e custos.

## Estrutura

- `business-model-canvas.html`: arquivo principal, pronto para abrir no navegador.
- `fluxograma-sistema.html`: pagina independente com fluxograma de uso em linguagem simples para orientar doadores, equipe administrativa e apresentacoes.
- `.gitignore`: regras básicas para evitar arquivos temporários no repositório.

## Como visualizar

Abra o arquivo `business-model-canvas.html` diretamente no navegador.

Para visualizar o fluxograma, abra `fluxograma-sistema.html`.

Também é possível servir a pasta com qualquer servidor estático simples, por exemplo:

```bash
npx serve .
```

## Publicação

Este repositório pode ser publicado como projeto estático no GitHub Pages, Vercel, Netlify ou qualquer hospedagem de arquivos HTML.

Na Vercel, basta importar o repositório e manter as configurações padrão para projeto estático.
