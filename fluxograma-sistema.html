Visao geral do sistema

O sistema combina uma aplicacao web responsiva para doadores e administradores com uma API REST responsavel por autenticacao, regras de negocio, gamificacao, notificacoes e persistencia dos dados.

W

Web responsiva

Landing, login, cadastro, dashboard, causas, mapa, historico, perfil e configuracoes.

U

Area do doador

Jornada autenticada com campanhas compativeis, agendamento, conquistas e notificacoes.

A

Painel admin

Estatisticas, usuarios, causas, doacoes, notificacoes, exportacoes e configuracoes.

D

Dados e seguranca

JWT, middlewares, validacoes, CORS, rate limit, Sequelize e banco PostgreSQL.

Fluxos principais

Os tres blocos abaixo mostram a jornada funcional do sistema: usuario comum, administracao e processamento tecnico da API.

Fluxo do doador

Uso publico e autenticado
1 Acesso publico Usuario entra na landing page, conhece o projeto e acessa login, cadastro, termos ou privacidade.
//login/register
2 Cadastro ou entrada Dados sao validados, a API autentica o usuario e o frontend armazena o token para requisicoes protegidas.
POST /auth/registerPOST /auth/login
3 Onboarding e perfil Usuario completa informacoes relevantes, como tipo sanguineo, contato, universidade e preferencias.
/onboarding/profile
4 Dashboard e campanhas Sistema apresenta indicadores, causas ativas, campanhas compativeis e conteudos educativos.
/dashboard/causes/education
5 Agendamento de doacao Doador escolhe uma causa ou hemocentro, agenda a doacao e acompanha status no historico.
POST /donations/donations
6 Engajamento continuo Notificacoes, ranking, conquistas e mapa mantem o doador conectado as proximas oportunidades.
/notifications/achievements/blood-centers

Processamento tecnico

Frontend, API e persistencia
1 React Router Define rotas publicas, rotas autenticadas e rotas administrativas protegidas por perfil.
ProtectedRouteAdminRoute
2 Estado local Stores controlam autenticacao, usuario, notificacoes e dados administrativos no frontend.
ZustandlocalStorage token
3 Cliente HTTP Axios envia requisicoes para a API e injeta o token JWT no cabecalho Authorization.
VITE_API_URLBearer token
4 Middlewares da API Express aplica CORS, helmet, rate limit, validacao de payload, autenticacao e permissoes admin.
authMiddlewareadminMiddlewareZod
5 Modulos de negocio Controllers e services executam regras de auth, usuarios, campanhas, doacoes, conquistas e notificacoes.
authcausesdonationsadmin
6 Banco e retorno Sequelize grava ou consulta o PostgreSQL e a API devolve JSON para atualizar a interface.
SequelizePostgreSQLJSON

Gestao e controle operacional

Arquitetura de alto nivel

Visao tecnica simplificada de como a aplicacao web conversa com a API e com os servicos de dados.

FE

Frontend

Aplicacao React com rotas, componentes reutilizaveis e estado local.

  • React, Vite e TypeScript.
  • React Router para navegacao.
  • Axios para comunicacao HTTP.
  • Tailwind e componentes UI.
->
API

API REST

Camada central de regras, seguranca e integracao entre tela e dados.

  • Express com rotas modulares.
  • JWT para autenticacao.
  • Helmet, CORS e rate limit.
  • Zod para validacao.
->
DB

Dados e apoio

Persistencia, consultas, exportacoes e servicos auxiliares.

  • PostgreSQL via Sequelize.
  • Modelos de usuarios, doacoes e campanhas.
  • Exportacao CSV para administracao.
  • Email e rotinas agendadas como apoio operacional.

Decisoes e regras importantes

Pontos de controle que explicam como o sistema protege acessos e organiza a experiencia dos perfis.

1

Sem token, sem area restrita

Rotas autenticadas redirecionam o usuario para login quando a sessao nao existe ou expira.

2

Admin exige permissao

O painel administrativo depende de autenticacao e verificacao de papel de usuario.

3

Campanhas orientam a jornada

Causas, compatibilidade sanguinea e notificacoes direcionam o engajamento do doador.

Conclusao tecnica

O Sangue Vivo ja apresenta uma separacao clara entre experiencia publica, jornada autenticada do doador, painel administrativo e API modular. Essa organizacao facilita evolucao para deploy profissional, auditoria de regras, integracao com dados reais de hemocentros e ampliacao futura de notificacoes, relatorios e automacoes de campanha.
